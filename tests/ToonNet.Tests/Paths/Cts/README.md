# JSONPath Compliance Test Suite

`cts.json` is the [JSONPath Compliance Test Suite](https://github.com/jsonpath-standard/jsonpath-compliance-test-suite)
for RFC 9535, commit `20ebdcce5008c8a777ee9c80ad853ecf606950b5` (2026-10-13), under the BSD-2 license in `LICENSE`.
`ToonPathComplianceTests` runs every case against `ToonPath`, with the JSON documents converted to `ToonValue` trees.
